About the project

This website is a fan-made final project built with HTML, CSS, vanilla JavaScript, Bootstrap, and Chart.js. The goal is to create a stylish and interactive website inspired by Don Toliver’s OCTANE album.

The design uses a brown, white, black, and gray theme to create a moody but clean look. It includes multiple interactive features such as song search, detail buttons, favorites, voting, hover effects, theme switching, and a back-to-top button.
